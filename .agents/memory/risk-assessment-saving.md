---
name: Risk assessment saving
description: Defines how learner risk-assessment saves behave.
---

A learner's ordinary risk-assessment or inspection-checklist save updates the latest working record; it does not create a new record on every press of Save. A learner can deliberately create a separate record by choosing Duplicate from the relevant History view.

**Why:** Each form presents one current working record. Creating a new record for every edit made History misleading, while some workflows still need a deliberate way to preserve a separate snapshot.

**How to apply:** Use the explicit Duplicate flow whenever a separate assessment or checklist record is needed. Keep routine saves clear in the interface, with an unambiguous success message and no alert-like sound.
