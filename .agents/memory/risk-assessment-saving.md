---
name: Risk assessment saving
description: Defines how learner risk-assessment saves behave.
---

A learner's ordinary risk-assessment or inspection-checklist save updates the latest working record; it does not create a new record on every press of Save. The learner-facing New Assessment/New Checklist action deliberately starts a fresh, separate history record. The History view's Duplicate action remains available when copying an existing record is useful.

**Why:** Each form presents one current working record. Creating a new record for every edit made History misleading, while some workflows still need a deliberate way to preserve a separate snapshot.

**How to apply:** Use New Assessment/New Checklist for a fresh record and Duplicate when copying an existing record. Keep routine update saves clear in the interface, with an unambiguous success message and no alert-like sound.
