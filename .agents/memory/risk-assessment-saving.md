---
name: Risk assessment saving
description: Defines how learner risk-assessment saves behave.
---

A learner's ordinary risk-assessment save updates their latest working assessment; it does not create a new record on every press of Save. A learner can deliberately create a separate record by choosing Duplicate from assessment History.

**Why:** The form presents one current working assessment. Creating a new record for every edit made the History list misleading and gave no indication that a successful save had occurred.

**How to apply:** Use the explicit Duplicate flow whenever a separate record is needed. Keep routine saves clear in the interface, with an unambiguous success message and no alert-like sound.
